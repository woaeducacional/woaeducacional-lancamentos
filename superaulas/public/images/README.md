# Artes da campanha

Origem: `Visual WOA.zip`, enviado pelo usuário. Conversão para WebP com qualidade 88, sem modificar o conteúdo das artes.

- `eagle.webp`: Aguia Galaxias .png — Aula 04.
- `ocean.webp`: Fundo Mar 01.png — fundo do hero e Aula 01.
- `ocean-floor.webp`: Fundo Mar 02.png — fundo inferior.
- `galaxy.webp`: Galaxias 01.png — Aula 03.
- `eagle-sunset.webp`: Terra Aguia 01.png — Aula 02.
- `ocean-mobile.webp`: Fundo Mar 03.png — disponível para ajustes futuros.

`Planos WOA.jpeg` é referência de composição e preços; a tabela continua HTML acessível. `Terra rio.png` não é necessária à composição atual. Arquivos originais permanecem no ZIP enviado. A logo sem fundo aprovada pelo usuário está em `woa-talk-logo.webp` (420 × 336, canal alfa preservado). O componente `BrandLogo` a utiliza no cabeçalho e rodapé com prefixo de subrota e dimensões responsivas.

Os PDFs em `public/materials` correspondem aos temas 01 a 04 do ZIP Aulas PDF. Foram apenas renomeados, sem modificar o conteúdo. Os vídeos complementares citados nos PDFs não foram incorporados como gravações das Superaulas.

`eagle-3d.webp`: nova arte gerada para a abertura, com aparência de renderização 3D, fundo transparente e dimensões 600 × 800. É uma imagem estática otimizada; não usa modelo 3D/WebGL. A arte original da Aula 04 foi preservada.
